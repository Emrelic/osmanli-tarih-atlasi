## Yontem notlari
- Madde = `devlet` alani kunye id'sine esit tekil maddeler + kunyenin gomulu `kronoloji` dizisi. Tahmini = devletsiz maddelerin `b`/`d` metninde kunye adi (tam ad veya parantezsiz taban, >=5 harf, normalize) gecmesi; yanlis pozitif icerebilir, TOPLAM DURUMA KATILMAZ.
- Yer: maddelerin `yer_id` (+ gomulu maddelerde `odak_yer`) adi; atlasta var = normalize ad veya parantezsiz/parantez ici alternatif ad motor girdi yerlesimlerinden birine uyar. Es adli yerler (homonim) yanlis "var" verebilir.
- Boya: id BOYALAR'da; "harita-anahtarindan" = id yok ama `harita:` anahtari var.
- s: yerlesimlerin `s[].d` kullanimi; hayalet = s donemi kunye f/t omrunu asiyor. Primary durum sirasi: madde eksik > yer eksik > boya eksik > hayalet > s yok > TAM.
- Listede id eslesmesi yalniz `id` ile; listede olmayan = "yok".
