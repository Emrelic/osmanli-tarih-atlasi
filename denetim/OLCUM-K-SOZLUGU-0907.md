# ① `k` SÖZLÜĞÜ NEREDE, KAÇ DEĞER, KİM OKUYOR

## 🔴 ÖNCÜL ÇÜRÜDÜ — TEK SÖZLÜK DEĞİL, ÜÇ

Sevk *"iki ayrı oturum aynı sözlükte birer boşluk ölçtü"* diyor. Ölçtüm —
`k` adı **üç ayrı alanı** taşıyor ve değer uzayları **hiç kesişmiyor**:

| # | nerede | ne | değer | kayıt |
|---|---|---|---|---|
| **A** | yerleşim kayıt seviyesi | idarî kademe | **5** (`0·1·2·3·4`, sayı) | 3253 |
| **B** | kronoloji madde seviyesi | konu/olay türü | **28** (dizgi) | 1268 |
| **C** | **`v:` dönemi içi** | tâbi yapının **ADI** | **40** (serbest metin) | 373 |

```
A ∩ B  = 0     (sayı ↔ dizgi, hiç örtüşmüyor)
`d:` · `s:` · `isg:` dönemlerinde `k:` YOK — C yalnız `v:`ye özgü
```

**A** `VERI-YAPISI.md:127`de tanımlı: *"İdari kademe 0-4. `0` = kademesiz
(yabancı şehir, dolgu), `1-2` = eyalet/sancak merkezi, `3-4` = alt kademe."*
**B** ve **C**'nin yazılı bir tanımı **bulunamadı** — `VERI-YAPISI.md`de
kronoloji `k:` için satır yok, `v:` içi `k:` için de yok.


## `tur:"son"` — sevkin kalemi

```
kuyrukta   tur:"son"  148 madde   ·  `k:` boş  148
çekirdekte tur:"son"    0 madde
```

Sevk *"5 madde `k:` boş kaldı"* diyor — o, taşınmayı **deneyen** oturumun
o turda gördüğü sayı. **Bütün `son` maddeleri taşınsa 148'i `k:` boş
kalır**, çünkü çekirdeğin 28 değerlik sözlüğünde `son`un karşılığı yok.
Ve `son` kuyruk `tur:` dağılımında **14. sırada** — yani tek başına da
değil: `hukumdar` 418 · `toprak-kazanc` 236 · `toprak-kayip` 184 · `din`
151 gibi değerlerin de çekirdekte karşılığı **yok** (28 değerlik B
listesinde geçmiyorlar).

⚠️ **ÖLÇMEDİM:** kuyruk `tur:` değerlerinin kaçının çekirdek `k:`
karşılığı **var**, kaçının **yok** — tam eşleme tablosunu çıkarmadım.
Yalnız `son` için ölçtüm.

# ④ OKUYAN TARAFIN MALİYETİ

## ④a Yeni bir değer eklemek — **A (yerleşim `k`)**

Dört satır dokunulmalı:

```
app.js:4749  KADEME_ADI   -> yeni başlık            eksikse: "undefined" yazar  🔇 SESSİZ
app.js:4753  kgruplar     -> yeni kova              eksikse: .push ÇÖKER        🔊 GÜRÜLTÜLÜ
app.js:4758  [1,2,3,4]    -> döngü listesi          eksikse: kova görünmez      🔇 SESSİZ
app.js:4756  !y.k         -> muhafız gözden geçir
```

🔴 **Üç dalın İKİSİ SESSİZ.** SERHAT'in koşturarak gösterdiği çökme
(`k:"S"` → şehirler sekmesi çöker) **en gürültülü** dal — yani en kolay
fark edilen. Sessiz iki dal daha pahalı.

**Muhafızın davranışı ölçüldü** — `!y.k` bir **falsy** testi, *"0 mı"*
testi değil:
```
k:0        falsy   -> SÜZÜLÜR, çökme yok   (bugün 1239 nokta, KASITLI)
k:5        truthy  -> kgruplar[5] tanımsız -> ÇÖKER
k:"S"      truthy  -> kgruplar["S"] tanımsız -> ÇÖKER
```
⇒ **0 dışındaki her yeni değer paneli çökertir.**

## ④b Yeni bir değer eklemek — **B (kronoloji `k`)**

```
app.js:1896  MUHAREBE_K   yalnız 4 değer eşliyor (savas·kusatma·isyan·ayaklanma)
app.js:1898  MUHAREBE_K[o.k]   eşleşmezse `undefined` — ÇÖKME YOK
```

⇒ **İki sözlüğün RİSK PROFİLİ ters:**
```
A (yerleşim)   yeni değer ÇÖKERTİR      -> gürültülü, hemen görülür
B (kronoloji)  yeni değer SESSİZCE düşer -> hiç görülmez
```
B'nin 28 değerinin **24'ü zaten** `MUHAREBE_K`de yok ve sessizce
eşleşmiyor — yani bu davranış **bugün de canlı**, yeni değere özgü değil.
