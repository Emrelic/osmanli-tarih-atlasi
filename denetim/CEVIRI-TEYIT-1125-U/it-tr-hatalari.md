# Türkçe kaynak hataları

- "# Ocak # (imzalar # Ocak-# Mart arası şeyhlik şeyhlik tamamlandı)": "şeyhlik" yinelenmiş, cümle bozuk.
- "Panel dar — tikla, KAPANSIN" / "Panel genis — tikla, DARALSIN" / "Panel kapali — tikla, GENISLESIN" / "⇥ Genislet": Türkçe harfler eksik.
- Devlet adlarında Türkçe harfsiz yazım: misir-* (Misir, Donem, Hanedan), sumer-lagas-1, akad, gutium, ur-3, isin, esnunna, samsi-adad, sealand-1, yeni-babil, orta-asur, mari-lim, elam-*, yeni-hitit, aram-sam, fenike-sehirleri, filistin-pentapolis, israil-krallik, ahamenis*, iskender-imparatorlugu (Buyuk), medine-devleti (Islam, donemi), zubeyri, uman-ibadi, numidia (birlesik); Çin/Kore/Japon/Hint/Amerika blokları (han-devleti-zhou "Savasan", bati-han, dogu-han, bati-jin ... tang, "Bes Hanedan", nara-japonya, maurya ... wari, maya-klasik "Sehir ... cati", atina-demokrasisi, likya-birligi, yeni-asur, chu-devleti, mayapan-birligi, dai-tuoba, xueyantuo-kaganligi, danimarka-erken, sarawak-tac-kolonisi, guney-yemen, birlesik-arap-emirlikleri, banglades, myanmar-birmanya, untaet, guney-kore, kuzey-kore-sovyet-idaresi, marshall-adalari, guney-vietnam, kampucya-halk-cumhuriyeti), neustria…balear-tavaif arası "Kralligi/Kontlugu", perlak "Sultanligi", ngo-hanedani, 12-su-quan "On Iki", vesali-chandra.
- sutayogullari, cemisgezek-beyligi: Türkçe harf eksik (Sutayoğulları, Çemişgezek Beyliği).
- varsova-dukaligi: "Varşova Büyük Dukalığı" — yerleşik ad Varşova Dukalığı.
- euboea-negroponte: "Venedik Krallığı" ifadesi şüpheli (Venedik yönetimi).
- bagdat-memlukleri: "(Eyüplü–Kölemen Hanedanı)" şüpheli.
- benevento-papalik: id papalık, ad "Benevento Prensliği" (kontrol edilmeli).
