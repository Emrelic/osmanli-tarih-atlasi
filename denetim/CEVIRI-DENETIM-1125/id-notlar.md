== notlar.md
## Toplu (betikle) düzeltilebilecek sistematik sorunlar - elle tek tek yazılmadı
- arayuz: "MÖ # (...)" kalıplarının neredeyse tamamı "SM # (...)" ; "MS # (...)" -> "M # (...)". Endonezcede doğru sıra "# SM" / "# M" (aynı sözlükte "# Agustus # SM", "# SM (tahun)" doğru). Öneri: ^SM # -> "# SM " ; ^M # -> "# M ".
- arayuz: "MÖ # civarı (...)" -> "SM # sekitar (...)" ; doğrusu "sekitar # SM (...)". Yalnız parantezsiz anahtar düzeltildi.
- arayuz: "# (YIL)" benzeri dışında uzun "# ... gecesi" gibi başka sözdizimi örnekleri kalmış olabilir.
- arayuz: Türkçe yer adları (Semendire=Smederevo, Tırnova=Tarnovo, Niş=Niš, Budin zaten Buda) kısmen Türkçe bırakılmış; yalnız açık olanlar düzeltildi.

== notlar_a.md
- "uç" (uç beyi, serbuan uç, beylik uç) 013-019 paketlerinde sistematik biçimde Endonezce metinde Türkçe terim olarak bırakılmış; toplu değiştirilmedi (yalnız 1463'teki melez ifade düzeltildi). Terim kararı gerek.
- "ocak" tek başına kalıntıları düzeltildi (korps); "ocaklık" terim olarak bırakıldı. 018+ dışında görülmeyen yerler olabilir.
- OLAYLAR_EK2:1557-10-16:0: Sinan'ın "kalfalık" eseri "karya magang" (çıraklık/staj çağrışımı) diye çevrilmiş; "karya tingkat madya/tukang mahir" düşünülebilir.
- "Mekah/Makkah", "Utsmani/Utsmaniyah" yazımları karışık (anlam hatası yok).

== notlar_b.md
- Hicrî ay adları karışık: bir kısmı Endonezce (Zulkaidah, Zulhijah, Ramadan, Safar), bir kısmı Türkçe biçimde (Cemâziyelevvel, Cemâziyelâhir, Rebîülevvel, Rebîülâhir). Yalnız Şaban/Şewal biçimleri düzeltildi; ötekiler için toplu karar gerekir.
- "bırakıldı" karşılığı "ditinggalkan kepada" kalıbı 036-049 aralığında sık; görülen belirgin yerler düzeltildi, başka paketlerde ve a etiketli aralıkta toplu aranmalı.
- Yazım paketten pakete değişiyor (Utsmaniyah/Utsmani, Paşa/Pasya, janisari/Janissari); zevk/tutarlılık sayıldı, değiştirilmedi.
- Düzeltme satırlarında "eski" alanı bazı kayıtlarda parçanın kısa tarifi/birleşimidir (ters bölü kayıtları, çok noktalı düzeltmeler); uygulama "yeni" (tam metin) üzerinden yapılmalı.
