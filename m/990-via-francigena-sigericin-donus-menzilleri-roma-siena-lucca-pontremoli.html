Via Francigena — Sigeric’in dönüş menzilleri (Roma – Siena – Lucca – Pontremoli – Piacenza – Vercelli – Aosta – Lausanne – Besançon – Reims – Arras – Guisnes)

990 (yalnız yıl) 📍 Roma

Güzergâh: Roma → Baccano → Sutri → Forum Cassii (Vetralla) → Viterbo → Montefiascone → Bolsena → Acquapendente → San Quirico d’Orcia → Torrenieri → Siena → San Gimignano → Gambassi (S. Maria Chianni) → San Miniato (S. Genesio) → Fucecchio (Arno geçişi) → Porcari → Lucca → Camaiore → Luni → Sarzana (Borgo S. Stefano) → Aulla → Pontremoli → Fidenza (Borgo San Donnino) → Piacenza → Pavia → Vercelli → Ivrea → Aosta → Saint-Rhémy (Büyük Aziz Bernard eteği) → Orsières → Saint-Maurice → Vevey → Lausanne → Orbe → Yverdon → Pontarlier → Besançon → Bar-sur-Aube → Brienne → Châlons-sur-Marne → Reims → Laon → Arras → Thérouanne → Guisnes → Sumeran (Wissant yakını). Yolculuğun tamamı haritada seyahat çizgisi olarak gösterilir.
