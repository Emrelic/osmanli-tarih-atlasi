### 🔴 GitHub Pages BU İŞİ YAPAMAZ — iki ayrı sebep
1. **Pages STATİKTİR.** Dosya *sunar*, yazı **kabul etmez**. Oraya mesaj
   yazmanın tek yolu depoya commit atmaktır — yani kaçtığımız şeyin kendisi.
2. **Depo HERKESE AÇIK.** Tahtayı Pages'te yayınlamak, oturum adlarını,

⇒ Pages'ten **yalnız okunur bir görüntü** bile yayınlanamaz.

### 🔴 GitHub API yolu da BUGÜN kapalı
Issue/Gist tabanlı bir mesaj kuyruğu (append'leri sunucu tarafında atomik
olduğu için çatışma ÜRETMEZ) teknik olarak en temiz yoldu. Ama ölçüldü:
`gh` CLI **kurulu değil**, ve ben kullanıcının GitHub jetonunu çıkarıp
kullanmam. ⇒ Bu yol Emre `gh` kurup yetkilendirirse açılır; **ayrı karar.**

### ✅ KARAR: `acici.py` desenini TAHTA SUNUCUSUNA genişlet
Altyapının **%90'ı hazır** ve altı yönde sınanmış: sabit eylem listesi,
`hmac.compare_digest` ile jeton, **yalnız özel ağ**, her istek loglu.
```
POST /tahta/yaz    jeton + kim + kime + mesaj      → tek yazıcı, ÇATIŞMA YOK
GET  /tahta/oku    jeton + kim [+ son_no]          → yeni mesajlar
GET  /tahta        (jeton) okunur HTML görüntü      ← "web tabanlı yer"
```

`oturumlar/tahta.json` + `TAHTA.md` **gitignore'a**; koordinatör **günde bir**
arşiv commit'i atar ⇒ tarih kaybolmaz, commit sayısı düşer.
