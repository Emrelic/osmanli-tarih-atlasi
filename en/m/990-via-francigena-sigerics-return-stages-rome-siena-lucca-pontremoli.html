Via Francigena — Sigeric's return stages (Rome – Siena – Lucca – Pontremoli – Piacenza – Vercelli – Aosta – Lausanne – Besançon – Reims – Arras – Guisnes)

990

Route: Rome → Baccano → Sutri → Forum Cassii (Vetralla) → Viterbo → Montefiascone → Bolsena → Acquapendente → San Quirico d'Orcia → Torrenieri → Siena → San Gimignano → Gambassi (S. Maria Chianni) → San Miniato (S. Genesio) → Fucecchio (Arno crossing) → Porcari → Lucca → Camaiore → Luni → Sarzana (Borgo S. Stefano) → Aulla → Pontremoli → Fidenza (Borgo San Donnino) → Piacenza → Pavia → Vercelli → Ivrea → Aosta → Saint-Rhémy (foot of the Great St Bernard) → Orsières → Saint-Maurice → Vevey → Lausanne → Orbe → Yverdon → Pontarlier → Besançon → Bar-sur-Aube → Brienne → Châlons-sur-Marne → Reims → Laon → Arras → Thérouanne → Guisnes → Sumeran (near Wissant).
